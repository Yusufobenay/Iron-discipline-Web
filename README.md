# Iron Discipline | Modern Fitness Landing Page

A responsive, dark-themed fitness landing page designed with modern UI standards.

## 🚀 Built With
- **HTML5**: Semantic layout structure
- **CSS3**: Modern styling with Flexbox & CSS Grid
- **Glassmorphism**: Backdrop blur interface panel
- **Responsive Web Design**: Mobile-friendly breakpoints

## 📌 Features
- Industrial matte-dark aesthetic with orange accents
- Overlapping glassmorphic info card
- Dynamic feature grid with clean SVG icons
- Scalable stats section
